# 闲鱼自动回复话术 30 句

按买家最常问的场景整理 30 句闲鱼自动回复话术：打招呼、问发货、问怎么用、砍价、售后、提醒收货和求好评，每句标好关键词和匹配方式，改成自己的说法就能用。

卖家经验 适用版本 1.6.0 更新于 2026-11-09

闲鱼买家问的话翻来覆去就那几句：在吗、什么时候发货、怎么用、能便宜点吗、收到没有。把这几类问题各写一句回复，再设成关键词自动回复，大部分消息就不用你亲自回。下面按场景整理了 30 句话术，每句都标了建议的关键词和匹配方式，改成你自己商品的说法就能用。

## 一、写话术的三条原则

1. **先回答问题，再说别的。**买家问「发货多久」，第一句就给时间，别先寒暄。
2. **一条规则只管一件事。**「在吗」和「怎么用」分开写，命中更准，改起来也方便。
3. **别引导站外交易。**回复里不要让买家加微信、去别处付款，容易被平台判违规；有些说法不能自动回，可以用违禁词兜底。

## 二、打招呼（4 句）

短词误触发多，「在」「在吗」建议用**精确匹配**，并打开「同一会话只自动回复一次」，免得买家每说一次都收到同一句。

| 关键词 | 匹配 | 话术 |
| --- | --- | --- |
| 在吗、在、你好 | 精确 | 1. 在的～宝贝直接拍就行，付款后自动发货，几秒就到。 |
| 在吗 | 精确 | 2. 您好，有货的，直接下单就好，有问题随时留言，看到马上回。 |
| 还有吗、有货吗 | 包含 | 3. 有货，链接在就有货，拍下自动发。 |
| 老板、掌柜 | 精确 | 4. 在的，想了解哪方面？发货、用法、售后都可以直接问。 |

## 三、问发货（5 句）

| 关键词 | 匹配 | 话术 |
| --- | --- | --- |
| 多久发货、什么时候发 | 包含 | 5. 付款后自动发货，一般几秒到一分钟，晚上也一样。 |
| 怎么发货、发什么 | 包含 | 6. 付款后会在这个聊天里自动发给您，链接和说明一起发，不用填地址。 |
| 没收到、没发货 | 包含 | 7. 发货内容在聊天记录里，往上翻一下就能看到；真没有的话留言订单号，我马上补发。 |
| 快递、包邮 | 包含 | 8. 这是虚拟商品，不走快递，付款后在聊天里直接发内容。 |
| 拍了、付款了、已付 | 包含 | 9. 收到，已经自动发出，请看上面的消息；有问题直接留言。 |

## 四、问怎么用（5 句）

讲步骤的回复，**文字加步骤图一起发**效果最好；不同商品用法不一样的，把规则限定到指定商品。

| 关键词 | 匹配 | 话术 |
| --- | --- | --- |
| 怎么用、怎么使用 | 包含 | 10. 步骤图发您了，照着第 1 步到第 3 步操作就行，大概两分钟。 |
| 怎么兑换、在哪兑换 | 包含 | 11. 打开对应 App 的兑换入口，长按复制兑换码粘贴进去就行，图里标了位置。 |
| 提取码、打不开 | 包含 | 12. 链接后面那 4 位就是提取码；打不开的话换个浏览器，或者复制整条链接再打开。 |
| 手机能用吗、电脑 | 包含 | 13. 手机和电脑都能用，说明里分别写了步骤。 |
| 教程、说明 | 包含 | 14. 使用说明在发货消息里，图文版也一起发您了，看不明白随时问。 |

## 五、砍价（5 句）

| 关键词 | 匹配 | 话术 |
| --- | --- | --- |
| 便宜、少点、优惠 | 包含 | 15. 已经是最低价了，量大的话可以留言说下数量。 |
| 能刀吗、小刀 | 包含 | 16. 价格是统一的，拍下就自动发，省得来回等。 |
| 包月、长期 | 包含 | 17. 长期用可以看下年卡规格，折下来每月更划算。 |
| 批发、多买 | 包含 | 18. 多买可以，留言需要的数量，我看到给您改价。 |
| 贵 | 精确 | 19. 理解～这个价格包含售后，用不了可以找我处理。 |

## 六、售后（5 句）

售后回复只负责先安抚、引导说清情况，真正处理要你本人看。

| 关键词 | 匹配 | 话术 |
| --- | --- | --- |
| 不能用、用不了、失效 | 包含 | 20. 抱歉给您添麻烦了，麻烦截个图发我，我看到第一时间处理。 |
| 码不对、错误 | 包含 | 21. 复制时注意别带上前后的文字，只复制码本身；还不行请截图发我。 |
| 退款、退货 | 包含 | 22. 收到，请说一下具体遇到了什么问题，我看完马上给您处理。 |
| 过期、到期 | 包含 | 23. 有效期写在说明里；如果还在有效期内用不了，截图发我核实。 |
| 人工、客服 | 包含 | 24. 在的，我本人看到就回，您先把问题写下来，回来直接处理。 |

## 七、确认收货与好评（6 句）

这一类不靠买家提问触发，是发货后主动发：自动提醒收货可以用自己的模板文案，收货后、好评后还能自动再送一份内容。

| 用在哪 | 话术 |
| --- | --- |
| 提醒收货（第一次） | 25. 东西用上了吗？没问题的话麻烦点一下确认收货，有问题直接找我。 |
| 提醒收货（再次） | 26. 打扰一下，订单还没确认收货，方便的时候点一下就好，谢谢～ |
| 求小红花 | 27. 用得满意的话送朵小红花吧，对我很重要，谢谢支持！ |
| 收货后 | 28. 谢谢确认收货！后面用着有问题随时找我。 |
| 好评后 | 29. 感谢好评～送您一份使用技巧，已经发在下面了。 |
| 关键词：谢谢、好的 | 30. 不客气，祝使用顺利，有需要再来～（建议精确匹配、只回复一次） |

## 八、在闲鱼智控里设置关键词回复

1. 打开「设置」→「智能回复」，点「新增回复」，回复类型选「关键词回复」。
2. 关键词逐个输入，每个按回车确认；正文粘贴上面的话术。
3. 选匹配方式：「包含」是消息里带这个词就触发，「精确」是整条消息和关键词一样才触发。
4. 讲步骤的规则，在同一条规则里上传步骤图，文字和图一起发。
5. 不同商品回不同内容：适用范围改成指定店铺和商品。

## 常见问题

### 闲鱼自动回复，「在吗」用包含还是精确？

用精确。「在」用包含的话，「在哪下载」「现在能用吗」都会被当成打招呼。长一点、意思明确的词（比如「多久发货」）用包含。

### 买家每次说「在吗」都会收到同一句吗？

可以避免：给问候类规则打开「同一会话只自动回复一次」，同一个买家只收到一次。

### 买家发语音，自动回复能识别吗？

能。闲鱼智控会把买家的语音自动转成文字，再按关键词匹配回复。

### 不想让某些话自动回复怎么办？

设违禁词：买家消息命中违禁词后，这个会话停止自动回复，交给你本人处理，防止乱答。

### 活动结束了，一批话术怎么一起停？

把这批规则放进同一个分组，活动结束点「停用组」，整组暂停，规则内容都保留。
