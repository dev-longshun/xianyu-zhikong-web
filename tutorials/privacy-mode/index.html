闲鱼截图隐私模式：店铺与商品信息一键打码

找到小眼睛开关，查看打码范围、悬停恢复、店铺代号与三项独立设置。

适用版本：2.2.0。

使用闲鱼智控 2.2.0。先接入至少一个店铺，消息和商品页有内容后，可照下面的步骤检查截图效果。基础版和高级版都能使用。

一、找到右上角的小眼睛

顶栏右上角，「悄悄看」和主题按钮中间的小眼睛就是开关，默认开启。带斜杠的眼睛高亮表示已开；把鼠标移上去，可以看到当前状态提示。

二、看清楚哪些信息会打码

店铺名换成「店铺1」「店铺2」，头像换成编号色块；店铺账号 ID 只保留前 3 位和后 2 位。商品图轻度模糊，商品标题换成一样长的灰条，商品 ID 只保留前 4 位和后 4 位。首页、消息、商品和店铺页同步显示，聊天里的商品卡片也适用。

三、自己查看：悬停商品，或关闭小眼睛

鼠标移到商品图、标题、商品 ID 上就显示原样，移开恢复打码。店铺名不给悬停查看；要看店铺真名，点小眼睛关闭隐私模式，截图之前再点开。

四、在店铺页起自己的代号

进入「店铺」页，点店名旁的小铅笔，填写「小七」这类自定义代号后保存。名字改成代号，头像显示代号的第一个字，顶上账号条也一起变化。清空代号再保存，会恢复「店铺N」。编号按账号条首次出现顺序分配，退出某个店铺后，其余店铺不会改号。

五、三项可以独立开关

进入「设置 → 通用设置 → 隐私模式」。总开关下有「店铺名与头像」「商品图与商品 ID」「商品标题」三项，可分别开关。例如仅关闭「商品标题」，标题恢复原文，店铺和商品图仍打码。总开关关闭时，三项置灰。

六、只改显示，只存本机

发给买家的消息、导出聊天、系统通知和邮件提醒照旧使用真名真图。隐私模式的开关、编号和代号只存本机，每台电脑各设各的；换电脑或重装客户端后，要重新设置代号。

买家的名字和头像不在打码范围内。要把聊天截图发给别人，买家一侧需要自己处理。

完成检查：看一眼右上角小眼睛已开启，店铺显示为代号、商品标题显示灰条，再截取需要的画面。
