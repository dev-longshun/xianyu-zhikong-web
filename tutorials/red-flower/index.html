小红花收下才算数

小红花是买家送给卖家的，收下才会记进你的累计。手机上求花要一单单点进订单，单子一多点不过来，忘了求的单，这朵花就没了。

打开自动求花和自动收花

  1. 确认店铺在线，在「营销」里打开「小红花权益」，点右上「自动求花 / 收花设置」。
  2. 打开「发货后自动求小红花」。延迟填 0 秒，就是一发货马上把求花卡片发给买家，不用等买家确认收货。每单只发一次；店铺掉线时，等重新连上再补发。
  3. 打开「买家送花后自动收下」，延迟默认 5 秒。
  4. 保存。两个开关分别生效，对你名下所有闲鱼店铺都适用。

配合自动发货，全程不用动手

买家付款，软件自动发货，求花卡片跟着发出；买家送了花，几秒后软件就收下，列表里这单显示「已收花」。自动发货的设置见自动发货教程。

开启前的老订单：批量求花

自动求花只对开启以后新发货的订单生效。之前的老订单，在小红花权益列表里勾选，点「批量求小红花」一次补上。30 天以内付款、已经发货的订单都能求；退款中和已关闭的订单不能勾选，会自动跳过。
