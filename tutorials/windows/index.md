# Windows 安装与激活

从下载安装包、完成安装，到输入激活码。按照图文步骤，完成闲鱼智控的首次安装。

图文教程 · 11 张操作截图 整理自原飞书安装教程

适用系统：64 位 Windows 10 / 11。截图保留原教程界面，下载区域与按钮位置可能随版本调整，请以当前页面为准。

本文将介绍闲鱼智控从下载安装包、完成安装，到输入激活码的完整操作流程。首次使用时，按照下方步骤依次操作即可。

开始前，请准备好闲鱼智控的下载链接和激活码。本教程以 Windows 电脑为例；如果浏览器在下载过程中显示安全提示，请先确认下载链接和安装包来源可靠，再继续操作。

## 一、下载安装包

打开[下载客户端](https://xianyu.dongeai.com/download/)页面，点击「下载 Windows 版」，浏览器便会开始下载安装包。

[![官网下载区域，选择 Windows 版](https://xianyu.dongeai.com/img/tutorials/windows/step-01.webp)](https://xianyu.dongeai.com/img/tutorials/windows/step-01.webp)

官网下载区域，选择 Windows 版 · 点击图片可放大

下载时，浏览器可能提示「通常不会下载此类安装包」。

[![浏览器下载列表中的安装包提示](https://xianyu.dongeai.com/img/tutorials/windows/step-02.webp)](https://xianyu.dongeai.com/img/tutorials/windows/step-02.webp)

浏览器下载列表中的安装包提示 · 点击图片可放大

确认安装包来源可靠后，接着，点击下载提示右侧的「···」，在菜单中选择「保留」

[![展开下载菜单并选择保留](https://xianyu.dongeai.com/img/tutorials/windows/step-03.webp)](https://xianyu.dongeai.com/img/tutorials/windows/step-03.webp)

展开下载菜单并选择保留 · 点击图片可放大

并在弹出的下一步点击「仍然保留」

[![确认来源后选择仍然保留](https://xianyu.dongeai.com/img/tutorials/windows/step-04.webp)](https://xianyu.dongeai.com/img/tutorials/windows/step-04.webp)

确认来源后选择仍然保留 · 点击图片可放大

完成这些操作后，安装包就会继续正常下载。请等待下载完成，再进行安装。

## 二、安装闲鱼智控

安装包下载完成后，打开文件所在位置

[![下载完成后打开文件所在位置](https://xianyu.dongeai.com/img/tutorials/windows/step-05.webp)](https://xianyu.dongeai.com/img/tutorials/windows/step-05.webp)

下载完成后打开文件所在位置 · 点击图片可放大

双击安装包启动安装程序。

[![双击下载完成的 Windows 安装包](https://xianyu.dongeai.com/img/tutorials/windows/step-06.webp)](https://xianyu.dongeai.com/img/tutorials/windows/step-06.webp)

双击下载完成的 Windows 安装包 · 点击图片可放大

等待安装窗口出现后，点击「下一步」。

[![在安装向导中点击下一步](https://xianyu.dongeai.com/img/tutorials/windows/step-07.webp)](https://xianyu.dongeai.com/img/tutorials/windows/step-07.webp)

在安装向导中点击下一步 · 点击图片可放大

进入安装路径选择页面时，可以使用默认路径，也可以选择自己希望安装的位置。

[![选择安装位置并开始安装](https://xianyu.dongeai.com/img/tutorials/windows/step-08.webp)](https://xianyu.dongeai.com/img/tutorials/windows/step-08.webp)

选择安装位置并开始安装 · 点击图片可放大

确认路径后，按照安装向导的提示继续操作，并等待安装完成。页面显示安装成功后，点击「完成」，闲鱼智控就会启动。

[![安装完成后启动闲鱼智控](https://xianyu.dongeai.com/img/tutorials/windows/step-09.webp)](https://xianyu.dongeai.com/img/tutorials/windows/step-09.webp)

安装完成后启动闲鱼智控 · 点击图片可放大

## 三、输入激活码

闲鱼智控启动后，找到界面右上角的「输入激活码」入口并点击。

[![点击客户端右上角的输入激活码](https://xianyu.dongeai.com/img/tutorials/windows/step-10.webp)](https://xianyu.dongeai.com/img/tutorials/windows/step-10.webp)

点击客户端右上角的输入激活码 · 点击图片可放大

将准备好的激活码输入到页面中，按照提示完成激活。激活成功后，就可以正常使用闲鱼智控了。

[![输入自己的激活码并确认激活](https://xianyu.dongeai.com/img/tutorials/windows/step-11.webp)](https://xianyu.dongeai.com/img/tutorials/windows/step-11.webp)

输入自己的激活码并确认激活 · 点击图片可放大

输入时建议核对激活码是否完整，留意是否多输入了空格。如果激活没有成功，可以先检查激活码，再重新尝试。
