# 闲鱼定时差评：按评价截止自动提交

在会话填写差评与截图，按30天或7天截止安排提交，邮件提醒帮助手机补交。

图文教程 · 8 张操作截图 适用版本 2.2.0 更新于 2026-11-22

适用版本：2.2.0。

先确认这单仍有平台评价入口，再填写有依据的评价内容与截图。定时差评需要软件保持运行和店铺在线。

## 一、先看懂30天评价期与7天回评期

交易成功后30天内可以评价；退款单仅限平台仍开放评价的订单，从退款成功起算。买家先评，截止取「完结后30天」和「买家评价后7天」较早的时间。交易直接关闭、或纠纷有判责结果的订单，平台不开放评价，软件显示「平台不开放」。

## 二、在会话里填写差评与截图

打开买家会话，右侧切到「订单记录」，点这单的「定时差评」。内容由你自己写，最多500字；截图最多5张，可以从本机拖入、粘贴或点加号添加，拖动调整顺序。默认匿名，保存后软件向平台核对能否评价，再计算截止时间。到点仍未填写内容的订单不会提交。

## 三、默认时间与自定时间

默认截止前3分钟提交，临近时查询买家最近来访，3小时内来过改为截止前1分钟。软件按闲鱼服务器时间校准。核对出截止后，可在「提交时间」选择自己的时间，最晚截止前1分钟；不想自定，点「恢复默认」再保存。

## 四、买家先评后自动改时间

收到买家「我完成了评价」卡，软件自动更新到买家评价后第7天的回评截止；如果30天评价截止更早，仍按更早的时间。可以回到这单查看新的截止与计划提交时间。

## 五、在定时差评列表看进度

进入「营销 → 去评价 → 定时差评」，查看截止、计划提交、当前状态。可切换进行中、已结束或全部。排了定时差评的订单会被自动好评和求好评跳过，避免先给出好评。

## 六、配置邮件提醒，必要时手机补交

在「设置 → 邮件提醒」配置发件邮箱和收件人，打开总开关与定时差评规则。默认提交前1小时通知，邮件含差评全文、截图附件。第一次提交失败会通知，可在手机闲鱼手动补交；有结果再通知。
