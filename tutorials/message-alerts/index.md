# 闲鱼新消息弹窗与超时未回复邮件提醒怎么设置

电脑前看弹窗，离开电脑收邮件；配置发件邮箱、开启超时未回复，再按需要设发送时段。

图文教程 · 5 张操作截图 适用版本 2.1.0 更新于 2026-11-20

适用版本：2.1.0。

新消息弹窗和图标提醒默认开启。邮件需要先配置发件邮箱，再打开总开关和超时未回复规则。

## 一、确认新消息弹窗和图标提醒

进入「设置 → 通用设置 → 消息提醒」，打开「新消息弹窗」和图标提醒。Mac 会显示系统通知、程序坞图标跳一下；Windows 会在右下角弹小窗，任务栏和托盘图标持续闪到回到客户端。只在闲鱼智控不在最前面时提醒，避免打扰正在处理消息的人。

[![两个消息提醒开关](https://xianyu.dongeai.com/img/tutorials/message-alerts/01-alert-settings.webp)](https://xianyu.dongeai.com/img/tutorials/message-alerts/01-alert-settings.webp)

两个消息提醒开关 · 点击图片可放大

## 二、配置发件邮箱

进入「设置 → 邮件提醒」，点「QQ 邮箱」或「163 邮箱」预设，填写发件邮箱、邮箱授权码和收件邮箱。QQ 邮箱用授权码，不是 QQ 密码；需先在邮箱网页版启用 POP3/IMAP/SMTP 并获取授权码。收件邮箱留空时发给自己。

[![填写发件邮箱、授权码与收件邮箱](https://xianyu.dongeai.com/img/tutorials/message-alerts/02-smtp-config.webp)](https://xianyu.dongeai.com/img/tutorials/message-alerts/02-smtp-config.webp)

填写发件邮箱、授权码与收件邮箱 · 点击图片可放大

## 三、先发送测试邮件，再保存

点「发送测试邮件」，确认显示成功，并到收件邮箱查看，必要时检查垃圾箱。确认后点「保存」保存发件配置。

[![测试邮件已发出](https://xianyu.dongeai.com/img/tutorials/message-alerts/03-test-success.webp)](https://xianyu.dongeai.com/img/tutorials/message-alerts/03-test-success.webp)

测试邮件已发出 · 点击图片可放大

## 四、启用超时未回复

打开「启用邮件提醒」，再打开「超时未回复：买家等 3 分钟没人回」。之后进来的消息等满 3 分钟，仍没人回复、也没人在客户端点开，就会收到一封带店铺、买家、商品和最后一句话的邮件。自动回复、自动发货、手机上回复都算处理过；同一次等待只提醒一次，追问不重复发。开启之前进来的消息不补发。

[![总开关和超时未回复规则都要打开](https://xianyu.dongeai.com/img/tutorials/message-alerts/04-timeout-enabled.webp)](https://xianyu.dongeai.com/img/tutorials/message-alerts/04-timeout-enabled.webp)

总开关和超时未回复规则都要打开 · 点击图片可放大

## 五、可选：只在一段时间发

打开「只在这段时间发」，选择开始和结束时间。等满 3 分钟那一刻落在时段外，就不发，进入时段后也不补发；不开时全天发送。

[![例如09:00至18:00，仅在选定时间发邮件](https://xianyu.dongeai.com/img/tutorials/message-alerts/05-send-window.webp)](https://xianyu.dongeai.com/img/tutorials/message-alerts/05-send-window.webp)

例如09:00至18:00，仅在选定时间发邮件 · 点击图片可放大

## 六、挂机时保持电脑醒着

后端每分钟检查一次，客户端窗口关闭也能继续检查；电脑睡眠或软件后端没运行时发不出去。需要挂机时到「设置 → 运行状态」打开「挂机不休眠」。
