适用版本：1.5.0。以下为本地示例环境的操作截图，店铺、商品、买家、订单和金额均为虚构；示例兑换码不可使用，示例链接无真实下载。

适合反复被问到的发货时间、怎么用、能否优惠等问题。先建立一条规则，再按需要增加图片、限定适用商品和设置回复频次。

一、确认店铺在线，打开回复管理

  1. 在「店铺」确认目标店铺在线，保持电脑联网、客户端运行。
  2. 打开「设置」→「智能回复」，进入回复管理，检查自动回复总开关处于开启状态。
  3. 点击「新增回复」。

二、创建一条关键词规则

  1. 填写规则名称，例如「砍价」，回复类型选择「关键词回复」。
  2. 关键词逐个输入，例如「便宜」「少点」「能刀」「优惠」，每填一个按回车确认。
  3. 填写自动回复正文，使用适合自己商品的话术。
  4. 确认「是否启用」打开，点「确定」保存。

完成检查：列表里出现新规则，关键词和回复正文正确，规则已启用。

三、选择包含匹配或精确匹配

  1. 编辑规则，找到「匹配方式」。
  2. 选「包含」时，买家消息带有关键词即可触发，例如「老板能便宜点吗」包含「便宜」。
  3. 选「精确」时，整条消息必须与关键词一致。对「在」这样的短词，优先考虑精确，减少「在哪下载」等误触发。
  4. 按实际需求选择后保存。

四、文字和步骤图一起回复

  1. 编辑需要讲操作步骤的规则。
  2. 保留文字说明，在同一条规则的图片区上传清晰的步骤图。
  3. 核对文字、图片与适用商品一致，保存。

完成检查：买家触发规则后，先收到文字，再收到图片。

五、给不同商品设置不同答案

  1. 在规则列表复制一条相似规则，再编辑副本。
  2. 适用范围改为「指定店铺和商品可用」，选中对应店铺，再选择「指定商品可用」。
  3. 点「选择商品」，勾选商品，确认。
  4. 修改规则名称与回复正文，移除不适用的旧图片；复制的规则默认停用，核对后再启用并保存。

完成检查：列表适用范围指向正确店铺和商品，买家在对应商品下提问时收到该商品的答案。

六、整理分组，避免重复打招呼

  1. 在智能回复列表点「新增分组」，输入容易辨认的名称，例如商品名或活动名，确认创建。
  2. 勾选需要整理的规则，点「移动到分组」，选择目标分组并确认。
  3. 活动结束后选中活动组，点「停用组」并确认，规则内容和各条规则自身开关保留。
  4. 编辑「在吗」等问候规则，需要时打开「同一会话只自动回复一次」，保存。

分组用来整理规则，不改变匹配顺序。规则和所在分组都需要启用，才会生效。

七、用提问检查触发结果

  1. 让买家在对应商品会话中发送一条能命中关键词的消息。
  2. 核对回复正文；配置了图片的，再核对图片是否发出。
  3. 未回复时，检查总开关、规则开关、分组状态、匹配方式与适用范围；还要确认是否已经触发「只回复一次」。

关键词规则由买家消息触发。付款后的交付需要在商品的付款后发货设置中配置。
